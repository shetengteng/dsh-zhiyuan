# CSV 表格预览与编辑

> 日期：2026-09-03  
> 状态：已实现，待 DSH Web 手工验收

## 用户看到的行为

知识库树中打开 CSV，与 Markdown 一样进入同一个预览弹框的编辑模式：可改表头和单元格，也可以新增/删除行列，点击保存后写回文件。

搜索命中卡和右侧详情仍是只读预览；它们与编辑态共用 `CsvPreview` 组件，只是传入的 `mode` 不同。

```text
树中打开 CSV
  → Host readMode=edit，返回完整逻辑记录
  → CsvPreview(mode=edit) / AG Grid
  → 保存
  → 私有 RPC write
  → Host 校验、规范化、原子替换

搜索命中
  → Host readMode=preview，只返回命中附近记录
  → CsvPreview(mode=read) / AG Grid
```

设置页与命中卡读取、保存都走 loopback 私有 RPC，不会把 CSV 正文写进会话。

## CSV 契约

- 第一条逻辑记录是表头；之后每条逻辑记录是一行数据。
- 可读入 UTF-8 CSV，解析逗号、分号、Tab、竖线分隔的常见形式，支持引号、转义双引号及引号内换行。
- 保存时统一写为 **UTF-8 BOM + 逗号分隔 + LF 换行**；所有字段保持字符串，`00123`、日期、`=...` 不会被当成数字或公式执行。
- CSV 最大文件为 `min(偏好单文件上限, 20 MiB)`，并同时检查单库配额。只读预览按逻辑记录截窗；编辑模式才读取完整表格。

## 组件与依赖

- `ag-grid-community@35.3.1` / `ag-grid-react@35.3.1`：React 18 兼容的表格展示、虚拟滚动与单元格编辑，MIT。
- `papaparse@5.7.0`：Host 解析记录及客户端保存时安全转义字段，MIT。
- 版本均在 `package.json` 和 lockfile 中精确锁定；构建将 `react`、`react-dom` 保持为 DSH 运行时外部依赖，不重复打包。

## 安全边界

- Client 不读磁盘、不自己决定可写性；Host 保留库根 containment、符号链接、UTF-8、控制字符、单行长度和 20 MiB 检查。
- 保存前 Host 再解析一次；畸形 CSV 不会覆盖原文件。
- 规范化内容先写入同目录唯一临时文件，再 rename 替换，写入失败时清理临时文件。
- 用户数据只作为 React 文本和 Grid 单元格显示，不插入 HTML，也不会写入日志。

## 已验证

- CSV 搜索命中的行窗口、高亮逻辑行。
- 逗号、分号、引号内逗号和跨行字段。
- 保存后的 UTF-8 BOM、逗号规范化及畸形 CSV 拒绝。
- CR / CRLF 物理换行。

仍需在 DSH Web 中手工确认：表格主题、键盘编辑、保存后的设置页刷新，以及接近 20 MiB 文件的交互流畅度。
