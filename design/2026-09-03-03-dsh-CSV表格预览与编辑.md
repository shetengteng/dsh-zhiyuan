# CSV 表格预览与编辑

> 日期：2026-09-03  
> 状态：已实现，待 DSH Web 手工验收

## 用户看到的行为

知识库树中打开 CSV，与 Markdown 一样进入同一个预览弹框的编辑模式：可在表格内直接修改表头和单元格，按 Enter 保存当前单元格、Esc 取消、Shift + Enter 在单元格中换行，点击保存后写回文件。

编辑器每页只显示 200 条逻辑记录，并提供上一页、下一页。它不提供公式、填充柄、复杂右键菜单以及行列插删，避免把预览弹框做成沉重的电子表格。

搜索命中卡和右侧详情仍是只读预览；它们与编辑态共用 `CsvPreview` 组件，只是传入的 `mode` 不同。

```text
树中打开 CSV
  → Host readMode=edit，返回首个 200 行页面和 revision
  → CsvPreview(mode=edit) / React Virtuoso 原生虚拟表格
  → 翻页：私有 RPC readCsvPage
  → 保存
  → 私有 RPC writeCsvPatch（只传修改过的单元格）
  → Host revision、边界、CSV 校验，规范化、原子替换

搜索命中
  → Host readMode=preview，只返回命中附近记录
  → CsvPreview(mode=read) / React Virtuoso 原生虚拟表格
```

设置页与命中卡读取、保存都走 loopback 私有 RPC，不会把 CSV 正文写进会话。

## CSV 契约

- 第一条逻辑记录是表头；之后每条逻辑记录是一行数据。
- 可读入 UTF-8 CSV，解析逗号、分号、Tab、竖线分隔的常见形式，支持引号、转义双引号及引号内换行。
- 保存时统一写为 **UTF-8 BOM + 逗号分隔 + LF 换行**；所有字段保持字符串，`00123`、日期、`=...` 不会被当成数字或公式执行。
- CSV 最大文件为 `min(偏好单文件上限, 20 MiB)`，并同时检查单库配额。只读预览至多返回 500 条逻辑记录和 200,000 字符；编辑模式虽由 Host 验证完整文件，但 Client 每次只接收 200 条记录。
- 编辑 patch 带文件字节的 SHA-256 revision。文件被外部改动、行列越界或 patch 过大时，Host 拒绝保存，不会覆盖当前文件。

## 组件与依赖

- `react-virtuoso@4.18.12`：MIT 的虚拟原生表格，负责固定表头和视口行渲染；单元格编辑由知源的受控 input/textarea 完成。
- `papaparse@5.7.0`：Host 解析、规范化和保存 CSV，MIT。
- 版本均在 `package.json` 和 lockfile 中精确锁定；构建将 `react`、`react-dom` 保持为 DSH 运行时外部依赖，不重复打包。

## 安全边界

- Client 不读磁盘、不自己决定可写性；Host 保留库根 containment、符号链接、UTF-8、控制字符、单行长度和 20 MiB 检查。
- Client 只持有当前分页和稀疏 patch；Host 在版本匹配后重新读取、解析并校验行列索引，再应用 patch。
- 保存前 Host 再解析一次；畸形 CSV 不会覆盖原文件。
- 规范化内容先写入同目录唯一临时文件，再 rename 替换，写入失败时清理临时文件。
- 用户数据只作为 React 文本和原生表格单元格显示，不插入 HTML，也不会写入日志。

## 已验证

- CSV 搜索命中的行窗口、高亮逻辑行。
- 逗号、分号、引号内逗号和跨行字段。
- 保存后的 UTF-8 BOM、逗号规范化及畸形 CSV 拒绝。
- 编辑分页上限、稀疏 patch、越界 patch 和 revision 冲突拒绝。
- CR / CRLF 物理换行。

仍需在 DSH Web 中手工确认：表格主题、键盘编辑、分页切换、保存后的设置页刷新，以及接近 20 MiB 文件的交互流畅度。
