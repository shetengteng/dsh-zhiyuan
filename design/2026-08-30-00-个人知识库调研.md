# 个人知识库主流方案（个人向）

> 日期：2026-08-30
> 范围：面向个人，不含企业搜索、团队 Wiki、会议转写 SaaS  
> 性质：公开评测与产品文档的二次整理，非实测验收

「知识库」在个人场景里至少拆成三件事：你自己写的笔记（PKM）、对已有文件提问（RAG）、让模型跨会话记住你（Memory）。单点产品很难三件事都做好，常见做法是主库 + 一层问答或记忆。

---

## 1. 结论先看

| 你实际要的 | 更稳的起点 | 代价 |
|---|---|---|
| 十年后还能打开的个人库 | Obsidian（Markdown 本地）或思源（中文块编辑、本地） | 要自己建结构和同步 |
| 大纲 / 日记驱动思考 | Logseq | 大纲心智，不是人人习惯 |
| 数据库 + 人生 OS，能协作 | Notion | 云端锁定，国内网络不稳 |
| 中文写作并对外发布 | 语雀 | 适合展示，不适合当唯一归档 |
| 读一堆 PDF / 论文再提问 | NotebookLM（源内引用最快） | 项目制，不是终身库；资料在 Google |
| 文件不能出本机 | AnythingLLM 或 Khoj（可接 Obsidian） | 要选模型、调检索 |
| 完全离线 | PrivateGPT + Ollama | 上手重，功能窄 |
| 让 Cursor / 聊天机器人记住你 | 本地 Markdown + MCP / mem0 | 笔记和记忆要分层，不要混成一个产品 |

2026 年的共识大致是：AI 检索已经是标配；分化点在 **数据放哪**（本地 vs 云）和 **知识单元是什么**（文档 / 块 / 对象 / 图谱 / 白板）。对象模型（Capacities、Tana、Anytype）在涨，但学习成本也高。个人认真用的主库，桌面仍然是主战场，手机多半只负责捕获。

---

## 2. 四条赛道

个人向「知识库」不是一类产品，是四类挤在同一个词下面。多数人买错，是因为把「写笔记」「问文件」「让 AI 记住我」当成了同一件事。

| 赛道 | 解决的问题 | 代表 | 不要用它做 |
|---|---|---|---|
| 笔记型 PKM | 写、链接、长期积累 | Obsidian / 思源 / Notion / Logseq | 临时丢一堆 PDF 就想问明白 |
| 文档问答 RAG | 对已有材料做有引用的问答 | NotebookLM / AnythingLLM / Khoj | 替代十年笔记习惯 |
| Agent 记忆 | 跨对话抽取并召回事实 | mem0 / Claude Projects | 当可编辑的知识主库 |
| 碎片捕获 | 把想法先记下来 | flomo / 系统备忘录 | 当成完整知识管理系统 |

复利来自双向链接和可迁移的文件，不来自「这个月的 AI 新功能」。RAG 是 2025–2026 真正爆的那一类，和笔记软件不是替代关系。

## 3. 代表产品对照

费用：免费 / 免费+增值 / 订阅。上手：低 / 中 / 高。

### 3.1 笔记型 PKM

| 产品 | 数据 | 费用 | AI | 上手 | 更适合 |
|---|---|---|---|---|---|
| Obsidian | 本地优先 | 免费+增值 | 插件自带模型 | 中 | 长期积累、要数据所有权 |
| 思源笔记 | 本地优先 | 免费+增值 | 插件 / API | 中 | 中文块编辑、离线个人库 |
| Logseq | 本地优先 | 免费 | 官方 Copilot + 插件 | 中 | 日记驱动、大纲思考 |
| Notion | 云端 SaaS | 免费+增值 | 原生 Agent / 工作流 | 低 | 数据库 + 人生 OS |
| 语雀 | 云端 SaaS | 免费+增值 | 通义系辅助 | 低 | 结构化写作与对外分享 |
| Capacities | 云端 SaaS | 免费+增值 | 对象级检索 | 中 | 人 / 书 / 会议等对象建模 |
| Tana | 云端 SaaS | 订阅 | 超标签 + Agent | 高 | 结构化工作记录自动沉淀 |
| Anytype | 本地优先 | 免费+增值 | 弱 | 中 | P2P 数据主权 |
| Heptabase | 云端 SaaS | 订阅 | 白板辅助 | 中 | 视觉拆解论文 / 课程 |

Obsidian 1.7 起有 Bases（在本地 Markdown + YAML 上做数据库视图），接近 Notion 的库能力，数据仍是磁盘上的明文。Notion 2026 已 bundling Calendar / Mail / AI Workflows，更像 work OS，离线与导出语义仍弱。思源是国内个人向本地块笔记的常见落点。

### 3.2 文档问答 RAG

| 产品 | 数据 | 费用 | AI | 上手 | 更适合 |
|---|---|---|---|---|---|
| NotebookLM | 云端 SaaS | 免费+增值 | 源内引用问答 | 低 | 按项目读资料、出摘要 |
| AnythingLLM | 可本地可云 | 免费 | 本地或云端 LLM | 中 | 把文件夹变成可问知识库 |
| Khoj | 可本地可云 | 免费+增值 | 语义搜索 + Agent | 中 | 对接 Obsidian 的个人 AI |
| PrivateGPT | 本地优先 | 免费 | 完全离线问答 | 高 | 空气隔离文档问答 |
| Open WebUI | 本地优先 | 免费 | Ollama + 文档聊天 | 中 | 已在跑本地模型的人 |

AnythingLLM 偏 RAG-first（工作区、引用、Agent）；Open WebUI 偏 chat-first、RAG 是附加；PrivateGPT 偏完全离线、功能窄。Khoj 更贴近「个人第二大脑 + 接 Obsidian / Emacs」。

### 3.3 Agent 记忆与碎片捕获

| 产品 | 赛道 | 数据 | 费用 | AI | 上手 | 更适合 |
|---|---|---|---|---|---|---|
| mem0 | Agent 记忆 | 可本地可云 | 免费+增值 | 跨会话事实抽取 | 高 | 给 Agent 持久记忆层 |
| Claude Projects | Agent 记忆 | 云端 SaaS | 订阅 | 项目级上下文 | 低 | 单项目资料喂给对话 |
| flomo | 碎片捕获 | 云端 SaaS | 免费+增值 | 弱 | 低 | 手机碎片想法先记下来 |

笔记库和 Agent 记忆是两层：前者是你写的资产，后者是模型跨会话抽取的事实。混成一个产品通常两边都弱。

## 4. 按人设选起点

| 人设 | 推荐起点 | 原因 |
|---|---|---|
| 长期写笔记、要自己掌控文件 | Obsidian 或思源做主库；需要数据库协作时才加 Notion | 个人知识的复利来自可检索、可链接、十年后还能打开的文件。纯云端 workspace 更适合协作，不适合当唯一归档 |
| 先读一堆 PDF / 论文再提问 | NotebookLM 做项目阅读；敏感材料改 AnythingLLM / Khoj | 需求是对一批源文件做有引用的问答，不是「建第二大脑」 |
| 想让 Cursor / 聊天机器人记住我 | Obsidian / 本地 Markdown 当源；mem0 或 MCP 当记忆层 | 笔记和记忆分层，不要混成一个产品 |
| 主要在中文环境、少翻墙 | 思源或 Obsidian 做库；语雀做对外发布；flomo 做捕获 | 国外云产品在国内网络和账号上不稳定 |
| 隐私优先、尽量不上云 | Obsidian 或思源做笔记；AnythingLLM 或 PrivateGPT 做问答 | 数据落磁盘，模型用 Ollama；同步用 iCloud / Syncthing / Git |

## 5. 三条常见个人栈

个人向很少有「一个 App 打天下」。

**本地主库** — Obsidian 或思源。Markdown / 块笔记落在磁盘，Git 或网盘同步。AI 用插件或本地 Ollama。适合把知识当资产攒十年。

**项目阅读** — NotebookLM + 主库摘录。每个课题一个 notebook，问答带引用。值得留下的结论再写回 Obsidian / 思源，避免材料只活在 Google 项目里。

**开发者 Agent** — 文件夹 + AnythingLLM / MCP。文档、仓库、笔记同一套检索。Cursor 通过 MCP 读库，而不是把正文粘进每次对话。

---

## 6. 选型时先问的三件事

1. **数据放哪**：要所有权、可 Git、怕服务停 → 本地 Markdown。要分享协作 → 云 workspace。本地可迁移，云端协作强但锁定高。
2. **你是在写，还是在问**：写选 PKM；对已有材料提问选 RAG；让模型记住你选 Memory。
3. **AI 能不能碰原文**：能上云用 NotebookLM / Notion AI；不能就 Ollama + AnythingLLM / Khoj。原生云 AI 省事，插件 / 自建模型更可控。

先定这三件事，再比功能清单。

## 7. 刻意未纳入

- 企业搜索（Glean 一类）
- 团队 Wiki 作主场景（Confluence、飞书知识库）
- 会议转写 SaaS（Otter 等）

那些是另一类产品。
