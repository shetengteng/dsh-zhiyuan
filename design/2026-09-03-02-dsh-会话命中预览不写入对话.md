# 知源：点击命中卡预览，不写入会话

> 状态：已实现（待 DSH Web 手工验收）

## 问题

点击 `kb_search` 的命中卡时，右侧预览需要读取原文并高亮命中行。

当前预览读取走的是：

```text
点击卡片
  → remote.commands.execute('/kb call { op: "read", ... }')
  → Host 返回 { path, text, ... }
  → 右侧预览显示并高亮
```

`remote.commands.execute` 绑定当前会话。Markdown 正文在返回的 `text` 中，因此可能被 DSH 当成一次命令结果留在对话里。重复点击会产生重复正文，这是不应有的。

## 目标

- 点击卡片后仍显示原文、命中位置和高亮。
- 预览读取不能生成用户消息、助手消息、工具调用或命令结果。
- `kb_search` 仍只向模型返回命中 excerpt，不能携带全文。
- 设置页面全部 Host 操作也不产生会话记录。
- Host 继续校验知识库、路径、符号链接、格式和命中位置。

## 目标流程

```text
kb_search 返回：路径、命中行、excerpt、文件指纹
  → 用户点击卡片
  → Client 私有 RPC：POST /zhiyuan/operation
  → Host 调用现有 readEntry(...) 并返回 ReadEntryResult
  → Client 内存中的 PreviewController 保存结果
  → 右侧 EntryPreviewContent 显示并高亮
```

这里的“私有 RPC”是 DSH `ctx.connection.rpc` 的 loopback-only channel，不能再包装成 `/kb call`，也不能经由 `remote.commands.execute`。返回值只交给当前浏览器组件，不进入会话事件流。

## 接口

Client 只发送已有命中卡中的定位信息：

```ts
operation({
  op: 'read',
  baseId,
  path,
  view: 'search-hit',
  matchLine,
  matchColumnByte,
  sourceFingerprint,
}, signal)
```

Host 返回现有 `ReadEntryResult`。`callKnowledgeHost(payload, signal)` 是组件唯一调用面；不新造第二套预览 DTO，不在 Client 读取本机文件。

Host 内部仍调用 `readEntry`，因此路径 containment、符号链接检查、格式白名单、CSV 严格 UTF-8 校验和只读能力判断全部保留。

## 设置页面的范围

设置页原先每次 `list`、切库 `tree`、预览 `read`、导入、搜索、编辑、删除、偏好保存和任务状态都会经由当前会话执行 `/kb call` 或 `/kb status`。现在：

- 所有业务操作统一走 `/zhiyuan/operation`；任务状态走 `/zhiyuan/status`。
- Client 不再注入 `remote.commands`、`sessions` 或 `workspaces`，因此也不会因为切库而新建、切换或写入会话。
- 显式输入 `/kb call {...}` 仍保留给命令用户使用，但与私有 RPC 共用 `executeKnowledgeOperation(...)`，不产生两套校验逻辑。

RPC 仅接受固定 operation 白名单；Host 在入口校验对象形状、字符串/数组/布尔值、预览定位、偏好正整数和额度关系，之后才调用已有的文件路径和符号链接防线。通道限制为 DSH loopback authority。

## 代码调整

- 保留 `KbSearchView`、`PreviewController`、`KbPreviewPanel` 和 `EntryPreviewContent`。
- 保留当前请求取消、旧请求结果丢弃、切换会话时清空预览的逻辑。
- 新增 `src/private-rpc.ts` 注册 Host channel，`src/private-rpc-contract.ts` 只保存双方可共享的 channel/endpoint 常量。
- 新增 `src/ui-operations.ts`，统一操作 allowlist 和 Host 输入校验。
- 将 `src/client/index.ts` 的 `loadPreview`、`SettingsSection` 全部改为私有 RPC。
- 不再让命中卡预览或设置操作调用 `/kb call { op: ... }`。

可选优化：PreviewController 以 `baseId + path + sourceFingerprint + matchLine` 做短期内存缓存；再次点击同一张卡直接显示缓存。切换会话、关闭详情栏或文件指纹变化时清掉缓存。

## 验收

1. 点击 Markdown 命中卡，右侧显示原文并高亮命中行。
2. 点击 CSV 命中卡，右侧显示命中附近窗口并高亮对应行。
3. 连续点击同一张卡或不同卡，不新增任何会话消息、命令记录或完整正文。
4. 切换卡片时取消旧请求；旧响应不能覆盖新卡片。
5. 手工修改文件后，指纹不匹配时显示 stale/fallback，不高亮旧命中。
6. 在设置页切库、导入、预览、搜索和保存偏好后，当前会话没有新增消息、命令记录或全文。
7. 私有 RPC 直接传入越界路径、非法行号或只读写请求时，Host 仍拒绝。
