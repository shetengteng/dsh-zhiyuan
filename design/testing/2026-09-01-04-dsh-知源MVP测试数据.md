# 知源（dsh-zhiyuan）MVP 测试数据

> 这些数据全部为合成内容，不包含真实合同、个人信息、账号、密钥或联系方式。  
> 可直接导入的文件位于仓库的 [`test/fixtures/zhiyuan-mvp/`](../test/fixtures/zhiyuan-mvp/)；本说明文档本身不要导入知识库。

## 1. 文件清单

```text
test/fixtures/zhiyuan-mvp/
├── 供应商合同.md
├── 会议/
│   └── 纪要.md
└── 冲突/
    └── 供应商合同.md
```

| 文件 | 用途 |
| --- | --- |
| `供应商合同.md` | 主流程：单文件导入、`合同/2024` 类目、违约/解约/termination/保密检索、完整预览 |
| `会议/纪要.md` | 多文件检索、中文目录、类目收窄；正文特意提到“违约”但不提供合同条款 |
| `冲突/供应商合同.md` | 与主文件同名但内容不同，用于验证不覆盖原文件而安全改名 |

## 2. 推荐初始化

在知源工作台创建知识库：

| 字段 | 值 |
| --- | --- |
| id | 系统自动生成 UUID，创建和编辑时不填写、不展示 |
| 标题 | `工作库` |
| 描述 | `公司合同、会议纪要和项目说明；提问工作资料时查这里。` |
| 别名 | `工作, 公司` |

建议先导入主文件：

1. 选择 `test/fixtures/zhiyuan-mvp/供应商合同.md`。
2. 目标类目填写 `合同/2024`。
3. 勾选“目录不存在则创建”，不要勾选“保留源目录结构”。
4. 导入成功后确认目标为 `bases/<baseId>/合同/2024/供应商合同.md`，源文件内容不变。

再导入整个 `test/fixtures/zhiyuan-mvp/` 文件夹到 `批量/2025`，勾选“保留源目录结构”，用于验证目录树和批量导入。

## 3. 冲突数据用法

先单独导入主文件到 `冲突测试`，再导入 `test/fixtures/zhiyuan-mvp/冲突/` 文件夹到同一个类目，且关闭“保留源目录结构”。预期：

- 内容相同的再次导入返回 `skipped`，不覆盖已有文件。
- 同名但内容不同的文件返回 `renamed`，生成 `供应商合同-2.md`（或实现约定的等价安全名称）。
- 原始文件和源文件都保持可读，源文件不被修改。

## 4. 固定 5 问数据预期

| 问题 | 参数 | 预期命中/结果 |
| --- | --- | --- |
| 1 | `违约` | 命中主合同的违约责任章节；批量导入后也可能命中会议纪要中的风险说明 |
| 2 | query=`违约`，aliases=`解约`、`termination` | 一次 OR 搜索命中主合同；结果中应出现对应路径和行号 |
| 3 | `保密` | 命中主合同的保密章节，片段包含保密期限或资料处理要求 |
| 4 | query=`违约`，category=`合同/2024` | 只看合同类目，不返回 `会议/纪要.md` |
| 5 | `火星基地预算` | `hits=[]`，不得生成测试数据之外的回答 |

## 5. 失败场景数据

用同一个「工作库」（使用创建结果中的 `<baseId>`）执行：

| 场景 | 输入 | 预期 |
| --- | --- | --- |
| 缺库 | `baseId=<missingBaseId>`，sourcePath 为主合同路径 | 拒绝并提示先建库，不创建对应的 `bases/<missingBaseId>` |
| 路径逃逸 | `destCategory=../life` | 拒绝，目标库和库外均无新文件 |
| 不支持后缀 | 准备任意名为 `sample.pdf` 的本地文件 | 该文件失败，其他合法文本可继续；当前 MVP 不支持 PDF |
| 缺少目标类目 | `/kb ingest <path> --base <baseId>`，且没有历史类目 | 提示指定 `--to` 或 `--root`，不自行散落 |
| 单文件过大 | 准备超过 5 MiB 的 `.md` 文件 | 该文件失败，不写入目标；同批其他合法小文件仍可处理 |

## 6. 离线测试

完成一次在线状态下的初始化和导入后，关闭网络连接，再执行：

1. 对主合同重复导入，验证 hash 去重。
2. 在工作台试搜 `违约`。
3. 在对话中执行自然语言 case `NL-001` 或 `NL-008`。

预期所有本地文件操作和 grep 检索继续完成；测试过程中不应把真实账号、token、个人文件路径或文件正文写入日志。
