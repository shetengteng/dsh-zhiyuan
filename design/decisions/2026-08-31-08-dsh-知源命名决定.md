# 知源命名决定

> 日期：2026-08-31  
> 序号：08  
> 状态：已决定

## 1. 决定

当前项目正式命名为 **知源**。

名称按不同使用场景分层：

| 场景 | 名称 |
|------|------|
| 项目 / 品牌名 | 知源 |
| 设置入口 / 工作台页标题 | 知源 |
| 产品对象（建库、导入、检索） | 知识库、类目 |
| npm / 插件包名 | `dsh-zhiyuan` |

原包名 `dsh-knowledge` 不再作为后续名称。

## 2. 命名理由

「知源」强调知识来自用户指定的原文，并且答案能够回到文件、路径和片段出处。

这个名称不绑定当前 MVP 的具体实现：

- 不绑定本地文件夹，未来可以扩展到云端存储；
- 不绑定 grep，未来可以替换为 FTS 或语义检索；
- 不绑定某一种模型，检索结果仍由当前对话模型处理；
- 能覆盖建库、导入、检索、引用和后续关联能力。

`dsh-zhiyuan` 保留 DSH 的归属，避免使用过于通用的 `zhiyuan`。

## 3. 对外用语

设置左侧 section 与工作台页标题写 **知源**。库、类目、导入、检索等产品对象仍用「知识库」「类目」，不写开柜、落柜。

推荐介绍语：

> 知源（DSH 知识库）：让 AI 从你指定的资料中查找答案，并保留原文出处。

## 4. 中英文描述

中文：

> 知源是 DSH 的本地优先知识库插件，帮助用户将 Markdown 和纯文本资料导入指定知识库，并通过可追溯的原文检索为 AI 提供可靠上下文。

English:

> Zhiyuan is a local-first knowledge base plugin for DSH. It helps users organize Markdown and plain-text documents into explicit knowledge bases and provides source-grounded search results for AI conversations.

适合写入 `package.json` 的简短英文描述：

> A local-first, source-grounded knowledge base plugin for DSH.

## 5. 不因命名而改变的内容

本决定只固化名称，不改变现有产品边界：

- 正文仍保存在知识库文件夹中；
- 用户显式创建知识库并指定导入位置；
- 查询时先选择知识库，再检索；
- 命中结果必须带文件和片段出处；
- 第一版仍只支持 md/txt、离线导入和本地检索。

## 6. 文件命名

- React 组件文件使用 PascalCase，并尽量与主要导出物一致，例如 `BasePage.tsx`、`SettingsSection.tsx`、`KbSearchView.tsx`。
- 同一职责的多个 React 展示物使用有语义的复数文件名，例如 `Dialogs.tsx`、`AdditionalDialogs.tsx`、`Icons.tsx`。
- Host 模块、Client 非组件模块和测试文件使用 kebab-case，例如 `command-parse.ts`、`host-resolve.ts`、`search.test.ts`。
- 设计文档使用 `YYYY-MM-DD-NN-dsh-主题.md`；历史研究文档不为追求形式统一而改名，避免破坏引用。
- 测试夹具可以使用中文业务名，例如 `供应商合同.md`、`会议/纪要.md`；这类名称用于验证真实用户路径，不套用源码命名规则。
