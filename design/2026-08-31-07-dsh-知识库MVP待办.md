- [x] `baseId` 必填：禁止省略后扫全部 `bases/`
- [x] `query` 必填

- [x] `topK` 默认 12，上限 20
- [x] 返回每条：`path`（库内相对）、`startLine`、`endLine`、`excerpt`、`[n]`

- [x] 中文路径 / 空格按字面；测试用「合同/2024」
- [x] 空库搜索 → 空列表
