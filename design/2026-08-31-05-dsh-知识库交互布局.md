# 知识库交互：操作台要显著，设置只放偏好

> 日期：2026-08-31  
> 序号：05（同日 01 TB 架构；02 文件夹 grep MVP；03 SQLite FTS；04 导入与分类）  
> 修订：2026-09-04 第一版入口从设置 `settings.section` 改为侧栏脚部 `sidebar.footer.action`；点开独立工作台弹层，不带设置左侧导航。对话命中预览改为 DSH 右侧 `details` 分区，工作台树预览仍用弹框。对照 `2026-08-31-07` 原型。  
> 对外用语：知识库 / 类目。界面不写开柜、落柜、柜门。  
> 对照 canvas：知识库交互布局。ASCII 每页单独一块，一行一行排，不对挤成一行。对话区顶栏/输入框上下为后续扩展。

建库、导入、目录树是工作台，不是插件窄卡。解析器、容量、默认库才进工作台「偏好」。主界面左侧「知识库」与工作区同级是页面 A；第一版挂侧栏脚部 → 知源。

| | |
|--|--|
| **可行** | 侧栏脚部 `sidebar.footer.action`：点开独立工作台弹层 |

## 两面拆开（第一版就按这个拆）

**工作台：侧栏脚部 → 知源**

挂 `sidebar.footer.action`，id=`zhiyuan`，label=知源，order=50。宽栏显示书本图标 +「知源」；窄栏只显示图标。点开 800×800 弹层（无设置左侧导航），里面：库列表、库卡片、类目树、导入、任务、检索试验。Esc、点遮罩、点右上角 × 关闭。工作台内弹框开着时 Esc 只关内层。

**偏好：工作台内「偏好」页**

默认库、单文件/单库上限。解析器：md/txt 勾上；不支持的置灰。不要再在插件窄卡里复制一份。

导入主路径是拖拽文件/文件夹或官方 directory-picker，不在工作台显示本机路径输入框。脚部弹层够画工作台；真正拷文件仍在主进程。

## 页面 B6 · 关于

使用说明。选库规则、如何导入、如何用自然语言问，都写在这里，不要写在空态或建库弹框里。不写工具名、不写 grep / SQLite。

```
关于

这是什么
  原文在本机。导入是复制进你指定的库。一次只查一个库。
  导入不会自动建库。

1. 建库
  新建 → 标题、描述、别名。id 由系统生成，标题不能重复。
  对话没点名库时，靠描述和别名选库；两个都像就问人。
  例：工作库 · 别名 工作, 公司 · 合同不要和生活账单混放。

2. 导入
  选库 → 导入 → 本机 md/txt → 类目 合同/2024 → 开始。
  缺文件夹可创建；缺库不创建。

3. 用自然语言问
  「去年那个供应商合同的违约条款写了什么？」→ 工作库，点命中卡看原文。
  「上个月水电费多少？」→ 生活库。
  「用工作库查 termination 条款」→ 已点名，不再猜。
```

## 对话里仍然要有的（第一版，不是工作台）

这些不是独立管理页，不另占设置左侧。第一版只做命中卡和斜杠；顶栏/输入框上下见下一节，后续扩展。

| 面 | 干什么 | 何时 |
|----|--------|------|
| `kb_search` 命中卡 | 矮卡、可多条叠放。点卡打开 DSH 右侧 `details` 分区，只读预览并高亮该句。不能改、不显示删除/保存。不跳工作台 | 第一版 |
| `/kb ingest`、`/kb status` | 无界面或键盘用户；`+` 打开 `/` 菜单会看到。参数与工作台同一套 | 第一版 |
| 悬浮 overlay | 快捷导入层 | 后做；有工作台就够 |

命中卡要矮：一次检索常有多条，叠着看。引用数字和路径同一行，数字**不带方括号**；片段最多两行，超出省略。整张卡可点，不要底栏再占一行「打开原文」。选中卡有描边。

```
+------------------------------------------+
| 1  合同/2024/供应商.md:3–4               |
| 若乙方违约，甲方可解除合同并收取违约金。   |
+------------------------------------------+
| 2  合同/2024/供应商.md:4–4               |
| termination 条款见附件三。               |
+------------------------------------------+
| 3  合同/2024/框架协议.md:3–3             |
| 双方就年度采购达成框架约定…              |
+------------------------------------------+
```

### 命中 → 右侧分区（不要绕去工作台）

卡上已经有路径、行号和句子，人已经定位到文本。不要再跳到侧栏脚部 → 知源让人自己在树里找文件。不要再弹出工作台那套预览弹框。

挂 DSH `details` slot：点卡 → `ctx.layout.openDetails()` → 右侧栏展示当前 hit。中间对话不跳转。换一张卡，右栏原地切换文件、行号和高亮。×、Esc 只关右栏。只读，无删除、无保存。

| 做 | 不做 |
|----|------|
| 打开 DSH 右侧 `details` 分区，只读 | 跳到知源工作台；弹出 B5 编辑弹框 |
| 滚到该句，高亮**这张卡**对应的那一句 | 打开文件停在开头、不标出句子；把全文关键词都涂上 |
| 文案不写「在知识库中查看」；整卡可点 | 「在知识库中查看」；底栏单独一行按钮 |
| 高亮与工作台试搜同一套 `<mark>` | 另做一套选区色 |
| 标题：文件名 + 引用数字；副行：第 a–b 行 · 命中第 n 行 | 会话里能改原文 |

```
+------------------+----------------------------------------------+--------------------------+
| 新会话           | 对话                                         | 供应商.md           1 × |
| 工作区           |                                              | 第 3–4 行 · 命中第 3 行  |
| 知源             | 去年那个供应商合同的违约条款写了什么？       |--------------------------|
| 设置             |                                              | # 供应商合同             |
|                  | 1  合同/2024/供应商.md:3–4                   |                          |
|                  |    若乙方违约，甲方可解除合同…               | 若乙方违约…  ← 高亮     |
|                  |                                              | `termination` 条款见附件三。 |
|                  | 根据 1：乙方违约时甲方可解除合同…             |                          |
+------------------+----------------------------------------------+--------------------------+
```

要改原文：去侧栏脚部 → 知源，在类目树里打开同一文件（走 B5 弹框）。

## 后续扩展 · 对话区上面和下面

对话顶栏、输入框上方、输入框内工具条、输入框下方都有官方加法座位（`ui-conversation` slot 合同）。**可以挂，不是改外壳。** 第一版不交这些，以免对话区再长出一套管理 UI。后续只做跳板和当前知识库提示，导入/建库仍在侧栏脚部 → 知源。

官方怎么分：

| 位置 | 座位 | 官方规定 | 我们后续怎么用 |
|------|------|----------|----------------|
| 对话框顶栏 | `conversation.session.header.actions` | 标题旁加法按钮，不换整个顶栏 | 「知识库」→ 打开知源工作台弹层 |
| 顶栏最右 | `header.utilities` | 工具类，别和标题旁动作抢序 | 一般不用 |
| 输入框上面 | `conversation.input.dock` | 整行：队列、todo、目标条。审批接管输入时整条会藏 | 慎用；不当常驻导入条 |
| 输入框内左 | `conversation.input.left` | 一行高小控件，跟在权限/计划/附件后，不替换它们 | 当前库芯片，点了只切换本会话默认库 |
| 输入框内右 | `conversation.input.right` | 一行高，发送键左边 | 不占；那里已有模型选择 |
| 输入框下面 | `conversation.composer.dock` | 环境读数；**要点的不要放这里**（统计行已在此） | 只读：当前库 · 篇数；失败时一行字 |
| 整块替换输入框 | `conversation.composer` 链 | 审批 / 提问接管 | 不要占 |

约束：这些槽都是 session 范围。`input.left` / `.right` 只有一行高。审批/提问接管 composer 时，上面的 dock 整组隐藏。不要占 `input.plan`、`input.model`。对话附件不是知识库文档。
