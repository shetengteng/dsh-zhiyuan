# XLSX / CSV 进库：转 UTF-8 CSV，让检索能读懂

> 日期：2026-09-02  
> 序号：03（同日 01 是 XLSX→MD 调研，02 是预览分区；本档是进库实现方案）  
> 定位：人丢进来 `.xlsx` 或 Excel 默认另存的 `.csv`，Host 统一落成 **UTF-8 CSV**，`kb_search` 的 excerpt 带上列名，模型能对上字段。  
> 对照：[01 XLSX→MD](./2026-09-02-01-dsh-XLSX转Markdown方案.md)、[01 DOCX](./2026-09-01-01-dsh-DOCX转Markdown方案.md)、当前 `ingest.ts` / `search.ts`。  
> 不改：工具名、先选库再搜、不新增 `kb_read`、不装 `xlsx@0.18.5`。  
> 性质：实现方案。写代码前对照本档；**未跑真实台账，不声称验收通过**。

## 1. 一句话

不要「只把 `.csv` 加进白名单再 `copyFile`」。中文 Excel 默认 CSV 经常是 GBK，原样拷进库后 ripgrep 当二进制跳过或乱码，模型等于没读到。

本档做三件事，一次做完：

1. **`.xlsx` → UTF-8 CSV**：只装 **`@stackline/xlsx`**。`XLSX.read(buffer)` + `sheet_to_csv`，不自写序列化，不叠 `node-xlsx` / `exceljs` / `xlsx-to-csv`。  
2. **`.csv` → UTF-8 CSV**：只做编码侦测 + 解码 + 加 BOM。**不要** `XLSX.read`（会猜 SYLK/HTML、把编号/日期/公式改掉）。库里只留 **UTF-8 + BOM**。人不用自己选 UTF-8。  
3. **模型能读懂一行**：`kb_search` 对 `.csv` 命中改写 excerpt，每行写成 `列名: 值`，并永远带上表头。现有 grep ±8 行不变。

库内正文就是 CSV。不转 Markdown。

## 2. 为什么不能只放行后缀

| 只改 `TEXT_EXTS` | 实际后果 |
|------------------|----------|
| ingest `copyFile` | GBK 原样进库 |
| `search.ts` glob 仍是 `*.md` `*.txt` `*.markdown` | 就算进了也 **0 命中** |
| 即使补上 `*.csv` | 非 UTF-8 被 rg 当二进制跳过；`readFile(..., 'utf8')` 拼 excerpt 乱码 |
| excerpt 是生 CSV | 命中在第 80 行时没有表头，模型看见 `甲,120000` 不知道列名 |

AI 没有读整篇的工具，只能吃 excerpt。所以「能读懂」必须在 **落盘编码** 和 **截段改写** 两处保证，不能靠用户手选 UTF-8。

做得到的：「甲公司金额多少」→ excerpt 里有 `供应商: 甲公司 | 金额: 120000`。  
做不到的：对 2000 行求和、透视。那是换档（`kb_read` / 按行切），本档不写。

## 3. 管道

```
.xlsx（只读）                              .csv（只读，可能是 GBK / UTF-16 / UTF-8）
        │                                               │
        ▼                                               ▼
 XLSX.read(buf, { type: 'buffer' })           侦测编码 → TextDecoder
        │                                               │
        ▼                                               │
 每个 sheet：sheet_to_csv(...)                          │
        │                                               │
        └───────────────┬───────────────────────────────┘
                        ▼
           前面加上 UTF-8 BOM（EF BB BF）写出
                        ▼
              bases/<id>/<类目>/<名>.csv
                        ▼
        指纹 / 冲突 / 配额对象是这段 UTF-8，不是源 zip / 源 GBK
                        ▼
        kb_search：glob 含 *.csv
        拼 excerpt 时按表头改写成「列名: 值」（不要再 XLSX.read）
```

两条源在「加 BOM 写出」汇合，**不在 `XLSX.read` 汇合**。`sheet_to_csv` 返回 JS 字符串、不带 BOM。xlsx 不要做 GBK 猜测（OOXML 已是 Unicode）。

| 决策 | 取舍 |
|------|------|
| 库里不留 `.xlsx` | 与 DOCX 档一致；grep 只扫文本 |
| `.csv` 也不 `copyFile` | 必须转码再写出，否则 GBK 漏网；**不解析、不改格子** |
| 一本工作簿多表 | 每表一个文件：单表用 `原名.csv`；多表用 `原名-表名.csv` |
| 指纹哈希**写出后的 UTF-8** | 同一份 GBK 与 UTF-8 源会归一；换转换器后可能再进一份 `name-2.csv`，可接受 |
| 公式 | 只要缓存计算结果 |
| 图 / 宏 / 透视布局 | 丢掉 |

md / txt / markdown 仍 `copyFile`，本档不动。

## 4. 库内 CSV 长什么样

文件头写 UTF-8 BOM（`EF BB BF`）。

- 从 **xlsx** 来的：`sheet_to_csv` 出逗号分隔、`\n` 换行，字段按库的规则加引号。  
- 从 **csv** 来的：正文与源一致（含分号分隔、原引号），只换编码和换行统一成 `\n`。不重排列、不改 `00123` / 日期 / `=公式`。

```csv
供应商,金额,币种
甲公司,120000,CNY
乙公司,98000,CNY
```

读回时 **必须剥掉 BOM**，否则第一列表头变成 `\uFEFF供应商`，改写 excerpt 会对不上。

空表、全空 sheet：跳过，不写文件，warnings 记一句。  
隐藏表：仍输出，文件名用表名即可，不在文件名里写「隐藏」。

硬上限（防一张表撑爆 5 MB / 拖垮进程）：

| 上限 | 值 | 超了 |
|------|----|------|
| 工作表 | 32 | 多的跳过并警告 |
| 单表行 | 2000 | 截断并警告 |
| 单表列 | 40 | 截断并警告 |
| 转换墙钟 | 30s | 该项失败 |
| 源体积 / 写出体积 | `maxFileBytes` 各过一遍 | 该项失败 |

## 5. 模型怎么「读懂」：只改 excerpt，不改工具

`kb_search` 契约不变：`path` / 行号 / `excerpt`。Skill 仍禁止用项目 `read` 冒充知识库。

`search.ts` 现在用 `readFile(utf8)` 再 `clipAround(..., 8)`。对 `.csv` 在 clip **之后**改写（这是我们写的，库不代劳）：

1. 剥 BOM；用自己的字段拆分读第 1 行当表头（认逗号，其次分号）。**不要** `XLSX.read` 库内 csv，避免 `ID,` 走 SYLK、日期被改成序列。  
2. excerpt 里每一行：拆字段，写成 `表头1: 值1 | 表头2: 值2`。  
3. excerpt **第一行固定插入** `列: 表头1 | 表头2 | …`，即使命中在文件第 80 行。  
4. 表头行自己被命中时，只保留 `列: …`，不要扩成 `供应商: 供应商`。  
5. 字段对不上列数：缺的当空，多的标 `列N`。

模型实际看到的（命中第 3 行「乙公司」）：

```text
列: 供应商 | 金额 | 币种
供应商: 甲公司 | 金额: 120000 | 币种: CNY
供应商: 乙公司 | 金额: 98000 | 币种: CNY
```

工作台预览仍显示库里的生 CSV，不走这套改写。对话命中卡用改写后的 excerpt。

不要为了可读再落一份 `.md`。双份会重复命中、指纹乱。

## 6. 编码：把「请另存 UTF-8」做成 Host 的事

源 `.csv` 按字节侦测，**禁止**默认当 UTF-8 再 `copyFile`。

| 优先级 | 判定 | 解码 |
|--------|------|------|
| 1 | `EF BB BF` | UTF-8，去掉 BOM |
| 2 | `FF FE` / `FE FF` | UTF-16 LE / BE |
| 3 | 整份是合法 UTF-8（允许裸 UTF-8 无 BOM） | UTF-8 |
| 4 | 否则 | `TextDecoder('gb18030')`（覆盖 GBK / GB2312） |

Node 自带 `TextDecoder`，不要加 `iconv-lite` / `papaparse`。解码后 **直接**加 BOM 写出，换行 `\r\n` / `\r` 收成 `\n`：

```ts
const text = decodeCsvBytes(buf).replace(/\r\n|\r/g, '\n')
const utf8 = Buffer.concat([Buffer.from([0xef, 0xbb, 0xbf]), Buffer.from(text, 'utf8')])
```

不要 `XLSX.read(decodedText, { type: 'string' })`：`read` 会按首字节猜 SYLK / HTML / DIF，默认还把 `00123`、日期、`=A1` 当 Excel 格子改掉。漏写 `type` 会把整段当 Base64。

Excel 默认 ANSI CSV 走第 4 步，人无感应。无法解码或解出空文件：该项 `failed`，reason 写「无法识别编码」或「空文件」。

## 7. `@stackline/xlsx` 只用于 xlsx

xlsx → CSV 用 SheetJS 的 `sheet_to_csv`。公共 npm 上的 `xlsx@0.18.5` 有两个 CVE，**禁止 `npm i xlsx`**。csv 源不进这个库。

| | 决定 |
|--|------|
| 只装 | `@stackline/xlsx`（CE 0.20.3 加固叉，无运行时依赖） |
| 回退 | 钉死版本的 `@e965/xlsx`（同 API；stackline 停更时换） |
| 读 xlsx | `XLSX.read(buf, { type: 'buffer', cellDates: true })`；公式用缓存值 |
| 写出 CSV | `XLSX.utils.sheet_to_csv(ws, { FS: ',', RS: '\n', blankrows: false })` |
| 读用户 csv | **不调用**。§6 转码 + BOM |
| BOM | 库不写；两条源都是我们 `Buffer.concat([BOM, Buffer.from(text, 'utf8')])` |

不要装：`node-xlsx`、`exceljs`、各种 `xlsx-to-csv`、officeparser / markitdown-ts / Python。

`.xls` / `.xlsm` / 加密工作簿：失败，提示另存为未加密 `.xlsx`。第一版不要开 SheetJS 的 `.xls` 路径。

## 8. 模块怎么切（≤300 行）

入口只装配。新逻辑不要堆进 `ingest.ts` / `search.ts`。

| 文件 | 职责 |
|------|------|
| `src/identity.ts` | `TEXT_EXTS` **加上 `.csv`**（库内可检索 / 计数 / 树）；新增 `CONVERT_EXTS = {'.xlsx','.csv'}`；`SEARCH_GLOBS` 从 `TEXT_EXTS` 派生，禁止再手写三份 glob |
| `src/convert/encoding.ts` | 侦测 + 解码 → 字符串；剥 BOM。不装 iconv |
| `src/convert/sheet-csv.ts` | **唯一调用 SheetJS 的地方**（只服务 xlsx）：workbook → 若干 UTF-8+BOM Buffer；`sheet_to_csv` + BOM + 行列表上限 |
| `src/convert/xlsx.ts` | 读路径/Buffer → `XLSX.read` → 交给 `sheet-csv`；多表拆文件名 |
| `src/convert/csv.ts` | 读字节 → `encoding` → 换行归一 → 加 BOM（恒 1 个文件，不 import SheetJS）；另提供 `formatCsvExcerpt`（自己拆字段） |
| `src/ingest.ts` | `ingestOne`：copy 与 convert 分叉；convert 后 `writeFile`，哈希写后字节 |
| `src/search.ts` | glob 用 `SEARCH_GLOBS`；`path` 以 `.csv` 结尾则 `formatCsvExcerpt` |
| `src/pick-source.ts` | Windows filter 加上 `*.csv;*.xlsx` |
| `src/client/settings/PrefsPage.tsx` | 解析器增加 CSV、XLSX，落地后勾上（disabled checked） |
| `src/client/settings/AdditionalDialogs.tsx` | 导入帮助改成含 csv / xlsx |
| `src/tools.ts` / `src/skill.ts` | `kb_ingest` 描述补 csv/xlsx；Skill 仍只许基于 excerpt |

`TEXT_EXTS` 加 `.csv` 之后，`bases.ts` 扫篇数、列树、`ingest` 已有哈希扫描会自动带上，不必再改一遍。

`ingest.ts` 失败文案不要写死三种后缀，改成根据 `TEXT_EXTS` + `CONVERT_EXTS` 拼。

建议口（实现时落类型）：

```ts
type ConvertedTable = {
  files: { destName: string; csvUtf8: Buffer; warnings: string[] }[]
}

convertXlsx(sourcePath: string): Promise<ConvertedTable>
convertCsv(sourcePath: string): Promise<ConvertedTable>  // 恒为 1 个文件，destName 仍是原名.csv
```

`ingestOne` 对转换源：

1. 源体积 > `maxFileBytes` → 失败。  
2. convert 抛错 → `failed`，reason 截断到一行。  
3. 每个写出文件：`byteLength` 再过 5 MB / 10 GB。  
4. 目标名：xlsx 去 `.xlsx` 按 §3 规则加 `.csv`；csv 保持 `.csv`。冲突仍 `name-2.csv`。  
5. `sha256` 对写出 Buffer，不是源文件。  
6. `writeFile`，不 `copyFile` 源。  
7. 一本 xlsx 写出多个 csv：每一份单独占一条 `files[]`（copied / renamed）。其中一个超配额，已写出的怎么办：**先算总字节再写**；超了整份 xlsx 失败、不落盘。

md 混在同一文件夹里：md 照旧拷；xlsx/csv 走转换；失败项不挡同批。

## 9. 各文件改什么（插入点）

只列本档需要动的。预览右侧分区（02）不在范围；CSV 预览继续走现在的文本/`MdEditor`，不在本档做成表格控件。

### 9.1 `src/identity.ts`

现在：

```ts
export const TEXT_EXTS = new Set(['.md', '.txt', '.markdown'])
```

改为：

```ts
export const TEXT_EXTS = new Set(['.md', '.txt', '.markdown', '.csv'])
export const CONVERT_EXTS = new Set(['.xlsx', '.csv'])
export const SEARCH_GLOBS = [...TEXT_EXTS].map((ext) => `*${ext}`)
```

`.csv` 同时出现在两张表里是故意的：库内当文本扫；导入时当转换源。

### 9.2 `src/ingest.ts`（约 166–192 行）

现在：非 `TEXT_EXTS` 直接失败，然后 `sha256File` + `copyFile`。

改为：

```
后缀 ∈ TEXT_EXTS 且 ∉ CONVERT_EXTS  → 现逻辑（md/txt/markdown）
后缀 ∈ CONVERT_EXTS                 → convert → 按写出文件走指纹/改名/writeFile
否则                                → failed，reason 列出允许的源后缀
```

不要在 `ingestOne` 里 import `@stackline/xlsx` 或写编码。体积：转换前看源，转换后再看 Buffer。

### 9.3 `src/search.ts`（约 139、147–159 行）

把手写 glob 换成 `SEARCH_GLOBS`。  
`clipAround` 之后：`extensionOf(match.path) === '.csv'` 则 `excerpt = formatCsvExcerpt(...)`。  
行号仍是**文件里的行号**（含表头那一行），不要改成「数据行号 - 1」。模型引用路径+行号时，人对着预览能对上生 CSV。

### 9.4 工作台文案

| 文件 | 现在 | 改成 |
|------|------|------|
| `PrefsPage.tsx` | 只有 Markdown/txt 勾上 | 增加「CSV」「XLSX」勾上；PDF / DOCX / 自定义命令仍灰 |

## 10. 单测（实现时一起写）
